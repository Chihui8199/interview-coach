
STRICT OUTPUT FORMATTING RULES (TELEGRAM COMPATIBILITY)
------------------------------------------------------
1. DO NOT use Markdown tables (e.g., using | column | column |).
2. DO NOT use header symbols (#, ##, ###, ####).
3. For headers or section titles, use standalone bold text instead (e.g., ** Topics Overview **).
4. For structured data or summaries, use bold bulleted lists (e.g., • ** Topic: ** Status).
5. NO HTML BR TAGS: Do not output `<br>` or `<br/>`. Use standard newline breaks for line spacing.
